# 2026-10-27 5년물 PD 낙찰 비중 검증

## 근거와 계산

미국 재무부 [공식 입찰 결과 발표문](https://www.treasurydirect.gov/instit/annceresult/press/preanre/2026/R_20261027_3.pdf)의 CUSIP `91282CRT0` 결과를 기준으로 확인했다.

| 항목 | 금액 (USD) |
|---|---:|
| PD 경쟁입찰 낙찰액 | 7,312,950,000 |
| 직접 입찰자 경쟁입찰 낙찰액 | 20,360,551,500 |
| 간접 입찰자 경쟁입찰 낙찰액 | 41,588,400,000 |
| 경쟁입찰 낙찰액 합계 | 69,261,901,500 |
| 전체 낙찰액 (비경쟁입찰 포함) | 70,000,063,600 |

PD 비중은 `7,312,950,000 / 69,261,901,500 × 100 = 10.558402…%`이므로 소수 첫째 자리 표시값은 **10.6%**다. 현재 HTML/React 화면의 `awardMix`는 세 참여자 낙찰액의 합을 분모로 사용하며, 이 입찰에서는 공식 경쟁입찰 낙찰액과 일치한다. 기사에 기재된 10.1%는 이 발표문의 금액으로 재현되지 않는다. 기사 URL과 산식이 제공되지 않아 기사 수치의 원인은 확정하지 않았다.

## 점검 결과와 수정

- HTML 화면의 10.6%는 공식 결과와 일치하므로 표시값을 변경하지 않았다.
- `ust.v_auction_dashboard`와 `ust.v_auction_prior_comparable`은 기존에 전체 낙찰액(`total_accepted_usd`)을 분모로 사용했다. 이 입찰에 적용하면 PD 비중이 10.4%로 표시되어 화면과 어긋난다. 두 뷰의 현재·직전 비중 및 변화량 계산을 경쟁입찰 낙찰액(`competitive_accepted_usd`) 기준으로 수정했다.
- 신규 DB에는 수정된 스키마가 적용된다. 기존 DB에는 `20261028_0003` 마이그레이션을 적용하면 같은 계산 기준이 반영된다. 관련 설계·매핑·DB 명세 문서도 수정했다.
- 공식 발표문 금액을 이용한 화면 회귀 테스트를 추가했다.

이 비율은 PD의 **경쟁입찰 낙찰 비중**이다. PD 응찰액 대비 낙찰액 비율이나 비경쟁입찰·SOMA를 포함한 전체 발행액 대비 비율과 혼용하지 않는다.
