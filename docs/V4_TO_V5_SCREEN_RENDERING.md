# v4 → v5 변경 사항: 화면 렌더링

비교 대상은 `UST_AUCTION_ui-baseline-v4.html`과 `UST_AUCTION_ui-baseline-v5.html`이다. 이 문서는 **잠정 일정의 표시와 화면 동작**에 초점을 둔다. 원천 수신·검증·병합은 [데이터 입수 문서](V4_TO_V5_DATA_ACQUISITION.md)에 정리했다. v5의 화면 수정은 주로 `scripts/acquire_tentative_schedule_v1.py`가 v4 HTML의 지정 위치를 치환해 생성한다.

## 핵심: 잠정 일정을 화면에 표시

| 화면 위치 | v4 | v5 |
| --- | --- | --- |
| 예정 입찰 일정표 | 공고되어 수신된 일정만 표시 | 공식 공고와 남은 잠정 행을 날짜순으로 함께 표시. 잠정 행은 `잠정` 배지, 예정 공고일이 지났으면 `공고 확인 필요` 배지 표시 |
| 일정 한눈에 보기 달력 | 결과·예정의 두 상태 | 결과·공고·잠정의 세 상태와 각각의 범례·월별 건수·색상 표시 |
| 좌측 선택 입찰 | 결과·예정 상태 | 잠정 행을 선택하면 `잠정` 상태 배지 표시 |
| 안내 문구 | 미공고 계획은 표시하지 않는다는 기존 안내 | 달력과 예정 일정표에 `잠정 일정은 공식 공고 전까지 변경될 수 있습니다.` 표시 |

잠정 행은 공식 공고 전 단계로 보이도록 회색 계열 색상과 테두리를 사용한다. 밝은 테마에서도 별도 색을 지정하고 범례 색을 일정 칸과 맞춘다. 공식 공고 예정 배지는 낮은 채도의 갈색과 흰 글자로 표시한다. 색과 배지 크기 등은 v5의 `ust-v5-tentative-styles`에 추가된다. 입찰 금액과 마감 시각이 없는 잠정 행은 추정하지 않으므로 기존 화면의 `N/A` 규칙을 따른다.

달력의 초기 월은 현재 표시 시간대의 당월로 설정된다. v4에서 기본으로 켜져 있던 `단기채 제외`를 v5에서는 해제해 4·6·8·13주물 등 단기채 일정도 처음부터 보인다. 사용자는 기존 체크박스로 다시 숨길 수 있다. 달력의 날짜·상품·만기 표시에는 10일 현금관리단기채 같은 `Day` 만기도 반영한다.

달력의 일정을 선택할 때는 예정 일정표 버튼에 넣은 `data-auction-key`와 **입찰 식별자·입찰일이 모두 일치하는 행**을 찾는다. 같은 만기의 다른 날짜를 잘못 선택하는 예전의 느슨한 대체 탐색은 제거했다. 잠정 행은 CUSIP 대신 날짜·종류·만기로 만든 `tentative:` 식별자를 사용한다.

## 기타 화면 변경

- 수집 상태 문구에서 `결과`, `공고`, `잠정`의 건수를 나누어 보여준다. Fiscal Data 재조회 실패 시에는 실패를 알리면서 사용 가능한 공고·잠정 수집본을 일정으로 표시한다.
- 한국어·영어 전환에 새 상태, 범례, 수집 메시지, 안내 문구를 추가했다. 단기채 `Day` 만기도 한국어 `일`과 영어 `D`로 변환한다. 제목 표기는 v4에서 v5로 갱신했다.
- 최근 입찰 결과 조회기간의 From 입력 앞에 엑셀 다운로드 버튼을 추가했다. `scripts/results_excel_v1.js`가 **현재 결과표의 열과 행**을 `UST_auction_results_YYYY-MM-DD.xlsx`로 저장한다. 결과가 없으면 머리글만 포함한다.
- 예정 입찰 일정 제목 옆의 자료 기준 문구와 상단 헤더의 자료 기준 시각 복제를 제거했다. 달력과 일정표에는 잠정 일정 변경 가능성 안내를 둔다.
- 시장 동향 카드의 금리 표시 자릿수를 소수 둘째 자리에서 넷째 자리로 바꾸고, 입찰 차트 축에서는 만기 문구를 제거해 날짜만 표시한다.

## 화면에 나타나는 데이터 범위

v5 HTML에 포함된 잠정 XML 스냅샷 전체가 화면에 보이는 것은 아니다. 브라우저 병합은 **조회일(UTC)부터 90일 이내**와 XML `calendarEnd` 이내를 모두 적용하고, 같은 입찰의 공식 결과나 공고가 있으면 잠정 행을 숨긴다. 저장된 수집본에는 2027-02-02 입찰 행이 있으나 `calendarEnd`가 2027-01-30이어서 현재 구현에서는 그 행이 표시되지 않는다. 수집 원본의 마지막 입찰일과 화면의 마지막 잠정 입찰일을 구분해야 한다.

화면 동작의 회귀검사는 `tests/tentative-schedule-v1.test.mjs`에서 공식 공고에 의한 잠정 행 대체, 단기채 기본 표시, 배지·범례·색상, 달력 선택, 영어 문구, 엑셀 버튼 등을 확인한다.
